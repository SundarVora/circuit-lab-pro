# Circuit Lab Pro

# Context

I am building a web-based electronic circuit simulator for beginners and hobbyists. 

# Task

Build the foundational UI and layout for the simulator. I want a responsive, single-page application. 

# Layout & Core Features

1. Sidebar (Left): A panel containing visually distinct, draggable electronic components (Resistor, Capacitor, Battery, Ground, Wire).

2. Main Canvas (Center): A large, interactive area where components will be dropped. Please use a node-based library like React Flow for this canvas.

3. Graphing Panel (Bottom): A resizable dashboard at the bottom designed to display an oscilloscope-style graph. Include a placeholder sine wave using Recharts or Chart.js.

# Aesthetics

The design should feel premium, modern, and developer-focused. Use a dark mode theme with a subtle dot-grid background on the main canvas. Use bright neon green or cyan accents for active components and graph lines to give it a technical, lab-equipment vibe. 

# Constraints

* Do NOT implement the actual circuit math or simulation logic yet. 

* Do NOT add a database, backend, or user login.

* Focus purely on a flawless, beautiful frontend layout with the drag-and-drop mechanics working visually.
